# Sahil Rohankar — Portfolio

Portfolio of Sahil Rohankar, Software Developer in Pune, India.

## Run locally

```bash
npm install
npm start
```

## Included

- Continuous, responsive sections with reference-style icon-rail navigation and active-section tracking
- Light and dark themes, saved in local storage and initialized from system preference
- Moving star layers, staggered animated lettering, animated section entrances, and a zooming hero mark inspired by the starter reference
- Scroll-triggered entrances, hover interactions, scroll progress, and a back-to-top control
- Resume download and contact links
- Experience, skills, education, and featured projects

The resume download is served from `public/Sahil-Rohankar-Resume.pdf`. Edit section copy and project cards in `src/components` as your experience changes.
